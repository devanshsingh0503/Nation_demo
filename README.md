# Nation (withnation.ai)

> **A store that runs and markets itself. One prompt starts a store.**

Nation is the agentic Shopify: one prompt, and a store builds itself, runs itself, and markets itself. AI agents do the manual work behind the scenes, and the seller approves with one click.

---

## ⚡ Tech Stack & Architecture

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Static Site Generation - SSG)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with a custom design token system
- **Animation Engine**: [GSAP](https://greensock.com/gsap/) + `@gsap/react`
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/) smooth scroll library
- **Icons & Vectors**: Precision SVG typography wordmark (`NATION`) with morph-to-nav animations
- **TypeScript**: Strict mode with full type safety

---

## 🚀 Key Features

1. **One-Prompt Store Creation (Builds)**
   - Store, product catalog, custom branding, and checkout built in under 60 seconds from natural language prompts.
2. **Autonomous Operations (Runs)**
   - Automated inventory deduction, supplier routing, delivery tracking, and 24/7 customer CRM.
   - 1-click mobile approvals for the seller.
3. **Ryze AI Ad Engine (Markets)**
   - Autonomous multi-channel advertising deployed across Meta (Instagram/Facebook), Google Ads, TikTok, and ChatGPT.
   - Dynamic creative testing and real-time ROAS optimization.
4. **Design System & Motion**
   - Staggered path blur entrance reveal.
   - Fluid logo scroll morph into the sticky navbar.
   - Dynamic dark/light theme switching.
   - Stacked sticky cards and custom text shuffle interactions.

## 🛠️ Getting Started

### Prerequisites

- Node.js 18.17+ or 20+
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/devanshsingh0503/Nation_demo.git
cd Nation_demo

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Generate static pages & optimize assets
npm run build

# Start the production server
npm run start
```
